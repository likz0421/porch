Porch 门廊 · Windows 版（动态域名 / HTTPS 证书 / 反向代理）

【启动】
  双击 start.bat —— 前台运行，能看到日志，关闭窗口即停止
  或直接运行 porch.exe（默认配置目录为程序同目录的 porchconf）

【访问】
  浏览器打开 http://127.0.0.1:16601
  默认账号 666  密码 666（登录后请到「系统设置」改掉）

【上手三步】
  1. 动态域名：让域名始终指向你家宽带的最新 IP
  2. SSL 证书：一键申请免费 HTTPS 证书，到期自动续
  3. 反向代理：把内网地址变成一个能在外网打开的网址
  概览页顶部有向导卡片，点一下就能跳到对应页面。

【开机自启】
  运行 autostart-install.bat，移除用 autostart-remove.bat。
  如需做成真正的 Windows 服务，可用 NSSM / WinSW 包装 porch.exe。

【防火墙】
  局域网其他设备访问时，需在管理员命令行放行端口：
  netsh advfirewall firewall add rule name="Porch" dir=in action=allow protocol=TCP localport=16601

【申请 SSL 证书】
  ACME 的 HTTP-01 需要监听 80 端口，Windows 上 1024 以下端口需要管理员权限，
  请右键"以管理员身份运行" start.bat，并确保 80 端口可从公网访问、域名已解析到本机。

【命令行参数】
  porch.exe -cd <配置目录>   指定配置目录（不存在会自动创建）
  porch.exe -p <端口>        临时指定管理端口
  porch.exe -v               查看版本
  porch.exe -open            启动后自动打开浏览器

【从 Lucky 迁移】
  管理界面 → 系统设置 → 从 Lucky 迁移，填写 Lucky 的配置目录即可
  （自动解密 lucky_ddns.lkcf / lucky_ssl.lkcf）

【旧配置】
  如果程序同目录下还留着升级前的 luckyconf 目录，Porch 会自动沿用它；
  也可以在停止服务后手动改名为 porchconf。
